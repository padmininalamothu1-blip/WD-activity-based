# Website Design Projects

## 1. Introduction

This project contains three website designs developed using HTML, CSS, and JavaScript. These websites are designed to be simple, attractive, user-friendly, and responsive.

The three websites are:
1. Online Food Ordering Website
2. Doctor Appointment Booking Website
3. Yoga and Meditation Website

## 2. Online Food Ordering Website

### Description
The Online Food Ordering Website allows users to explore restaurants, view food items, check prices, and add their favorite dishes to a shopping cart.

### Features
- Restaurant details and ratings.
- Food categories and food images.
- Food prices and special offers.
- Customer reviews.
- Add to Cart and Order Now buttons.
- Shopping cart with quantity controls.
- Mobile-friendly design.

### Technologies Used
- HTML – Creates the website structure.
- CSS – Adds colors, backgrounds, and card layouts.
- JavaScript – Handles food search, categories, and shopping cart operations.

### How It Works
Users browse the food menu, select their favorite dishes, add them to the cart, and view the total price before placing a demo order.

## 3. Doctor Appointment Booking Website

### Description
The Doctor Appointment Booking Website helps users view doctors, check their specialties, and book appointments through a simple interface.

### Features
- Doctor profiles and photographs.
- Doctor names and specializations.
- Hospital or clinic details.
- Available appointment dates and times.
- Appointment booking form.
- Patient contact details.
- Appointment confirmation message.
- Responsive design for mobile devices.

### Technologies Used
- HTML – Creates doctor profiles and booking forms.
- CSS – Designs the website layout and appointment cards.
- JavaScript – Checks form inputs and displays booking confirmation.

### How It Works
Users select a doctor, enter their details, choose an available appointment time, and submit the booking form. The website displays a confirmation message.

*Note: This is a demonstration project. Real appointment scheduling requires a backend system.*

## 4. Yoga and Meditation Website

### Description
The Yoga and Meditation Website provides information about yoga exercises, meditation techniques, and healthy lifestyle practices. It helps users explore activities that support relaxation and general well-being.

### Features
- Yoga and meditation information.
- Images of yoga poses.
- Different yoga exercise categories.
- Meditation guides and breathing exercises.
- Daily practice schedules
